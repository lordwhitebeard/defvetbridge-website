# DefVetBridge website

The one-page public website for DefVetBridge (DVB): what it is, how it works, and how to support it.

- Live at https://www.defvetbridge.com (Cloudflare Pages, deployed automatically from the `main` branch)
- Plain HTML and CSS, no build step. Edit `index.html`, commit, push: Cloudflare redeploys in about a minute.
- Donations go through PayPal (hosted button `S4E4LCPC5ER3N`).

This repository holds only the public website. The DVB application itself lives elsewhere.
